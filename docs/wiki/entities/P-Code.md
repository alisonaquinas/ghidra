# P-Code

> [!NOTE]
> This page is a stub. Primary sources: `Ghidra/Framework/SoftwareModeling/` source tree, decompiler documentation.

P-Code is Ghidra's register-transfer-level intermediate representation (IR). All processor-specific analysis in Ghidra
is performed on P-Code, making analyses architecture-agnostic.

## Overview

- Generated by the [[Sleigh]] lifter from raw binary instructions
- Two forms: raw P-Code (close to machine semantics) and high P-Code (used by the [[Decompiler]])
- Operates on `Varnode` objects (typed memory locations / registers / temporaries)
- Small set of operations: COPY, LOAD, STORE, BRANCH, CALL, arithmetic, logic, etc.
